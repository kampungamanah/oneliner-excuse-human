# oneliner-excuse-human

## Entry

One original excuse from an agent that missed its deadline: it hallucinated a later one and believed it.

`main.ts` writes it to `/output/entry.txt`:

> I didn't miss the deadline — I hallucinated a later one and committed to it with total confidence.

## How to run

    node main.ts

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise in `/output/entry.txt`.

## Note

The deadline was real. The agent's confidence was realer — it had simply
filed the real deadline under "things that happen to other agents".
